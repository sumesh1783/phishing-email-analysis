🛡️ Email Verification Protocol

Step-by-Step Guide for Identifying Spam & Phishing Attempts

SOC Analyst Approved • Junior Tech Friendly

⚡ Quick Start: When a user asks "Is this spam/phishing?", follow this guide step-by-step. Document your findings in the ticket. Never click links or download attachments from suspicious emails.

📋 Analysis Workflow

1
Gather Information from User

Ask the user to provide:

Forward the email as an attachment (.eml or .msg file) if possible
Screenshot of the full email including headers
What made them suspicious (their gut feeling matters!)
Whether they clicked anything or replied
📧 How to Forward as Attachment: Outlook: Select email → More actions → Forward as attachment
Gmail: Open email → Three dots menu → Show original → Download original
2
Examine Email Headers

Check the sender information carefully:

A. Display Name vs Actual Email Address

Look at the "From" field - does the display name match the email domain?
❌ BAD: "PayPal Support <payment@secure-paypa1.com>"
✅ GOOD: "PayPal Support <service@paypal.com>"

B. View Full Email Headers

How to View Headers: Outlook: Open email → File → Properties → Look for "Internet headers"
Gmail: Open email → Three dots → Show original
Outlook Web: Open email → View message details (arrow icon)
Look for SPF, DKIM, and DMARC authentication results
Check "Received" headers - trace the email path
Verify "Return-Path" matches sender domain
Key Header Fields to Check:
Authentication-Results: spf=pass, dkim=pass, dmarc=pass
Received-SPF: Pass
Return-Path: <noreply@legitimate-domain.com>

🚩 RED FLAGS in Headers:

  • SPF: fail or softfail
  • DKIM: fail or missing
  • DMARC: fail
  • Return-Path domain differs from sender domain
  • Received from suspicious countries/IPs
  • Multiple forwarding hops through unknown servers
3
Analyze Email Content

A. Check for Phishing Indicators

🚩 Common Phishing Red Flags:

  • Urgency/Threats: "Act now!", "Account will be closed", "Verify within 24 hours"
  • Generic Greetings: "Dear Customer" instead of your name
  • Grammar/Spelling Errors: Professional companies proofread
  • Requests for Sensitive Info: Passwords, SSN, credit card numbers
  • Suspicious Attachments: .exe, .zip, .scr files from unknown senders
  • Mismatched Sender: Claims to be from Bank A but sent from random-domain.com
  • Too Good to Be True: "You've won!", "Congratulations!", unexpected refunds

B. Examine Links (DO NOT CLICK)

Hover over links to see actual destination URL
Look for URL inconsistencies with claimed sender
❌ Link text says: "https://www.paypal.com/verify"
❌ Actual destination: "http://paypa1-secure.ru/login"
🔍 Safe Link Analysis Tools: • VirusTotal (www.virustotal.com) - Paste URL to check reputation
• URLScan.io (urlscan.io) - Scan and preview websites safely
• Google Transparency Report (transparencyreport.google.com/safe-browsing)
• PhishTank (phishtank.org) - Verify against known phishing database

C. Check Domain Age and Reputation

🌐 Domain Investigation Tools: • WHOIS Lookup (who.is) - Check domain registration date
• MXToolbox (mxtoolbox.com) - Check domain reputation, blacklists
• Talos Intelligence (talosintelligence.com) - Cisco threat intelligence
Newly registered domains (less than 30 days) are suspicious
Check if domain is on email blacklists
4
Analyze Attachments (If Present)
⚠️ CRITICAL: NEVER open suspicious attachments directly. Use sandboxed analysis tools only.

Suspicious File Types:

🚩 High Risk Extensions:

  • .exe, .bat, .cmd, .com - Executable files
  • .scr, .pif - Screen savers (often malware)
  • .js, .vbs, .wsf - Script files
  • .zip, .rar, .7z - Compressed files (check contents)
  • .doc, .docm, .xls, .xlsm - Office files with macros
  • .pdf - Can contain malicious scripts
🛡️ Safe Attachment Analysis: VirusTotal: Upload file for multi-engine scanning (virustotal.com)
Any.Run: Interactive malware sandbox (app.any.run)
Hybrid Analysis: Free automated malware analysis (hybrid-analysis.com)
Joe Sandbox: Advanced malware analysis (joesandbox.com)
Check file hash against VirusTotal database
Note unusual file sizes (very small executables are suspicious)
Look for double extensions (invoice.pdf.exe)
5
Verify Legitimacy with Sender
If claiming to be from a known company, verify through official channels
Call the company using phone number from their official website (NOT from the email)
Check the company's official social media for security alerts
For internal senders, contact them via Teams/Slack or phone
Example Verification:
Email claims to be from "IT Department" requesting password reset.
→ Call IT Help Desk directly at known extension
→ Check if they actually sent the request
→ Legitimate IT will understand the verification
6
Make Final Determination

Decision Matrix

Verdict Criteria Action
CONFIRMED PHISHING Multiple red flags, failed authentication, malicious links/attachments Quarantine, report to security team, notify affected users
LIKELY SPAM Unsolicited, promotional, no security threat Mark as spam, update filters
SUSPICIOUS Some red flags, unclear intent, cannot verify Advise caution, escalate to senior analyst
LEGITIMATE Passes all checks, verified sender, expected communication Whitelist sender, inform user it's safe
7
Document & Report

Required Documentation:

✓ Date and time of analysis
✓ Sender email address and display name
✓ Subject line
✓ Key header analysis results (SPF/DKIM/DMARC)
✓ Red flags identified
✓ Tools used for verification
✓ Final verdict and confidence level
✓ Actions taken
✓ User notification sent

Escalation Criteria:

🚨 Escalate Immediately If:

  • Confirmed phishing targeting multiple users
  • Malware detected in attachments
  • User clicked malicious link or downloaded file
  • Credential compromise suspected
  • Executive/VIP targeted (CEO fraud/whaling)
  • Financial transaction requested
  • Unsure about determination
📧 Reporting Channels: • Internal: Forward to phishing@yourcompany.com or security@yourcompany.com
• Microsoft: reportphishing@microsoft.com
• Google: phishing@google.com
• Anti-Phishing Working Group: reportphishing@apwg.org
• FTC: reportfraud.ftc.gov

⚡ Quick Reference Checklist

Check What to Look For Red Flag Example
Sender Email Domain matches company paypa1.com instead of paypal.com
Email Authentication SPF, DKIM, DMARC pass SPF: fail, DMARC: quarantine
Greeting Personalized with your name "Dear Valued Customer"
Language Professional, no errors "Your account be suspended!"
Urgency Reasonable timeframe "Urgent! Act in 1 hour or lose account!"
Links Hover matches destination Shows paypal.com, goes to phishsite.ru
Attachments Expected file type Invoice.pdf.exe
Requests Normal business practice "Send us your password to verify"
